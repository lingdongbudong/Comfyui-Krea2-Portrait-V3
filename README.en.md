## What it is

A random **photographic portrait prompt generator** for Krea2 workflows. No LLM, no network:
it fills a fixed 10-section template from **63 pools / 949 Chinese entries**, with character
linking, content grading, three-layer weights and a reproducible seed.

Fully local · zero dependencies · runtime offline ·
**generates prompts only, never images**.

## What's inside

| Item | Count |
| --- | --- |
| Pools | **63** / 949 entries |
| Assembly | 10-section template |
| Characters | **2,165** |
| Nodes | 3 |

## Install

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/lingdongbudong/Comfyui-Krea2-Portrait-V3.git
```

Restart ComfyUI. No dependencies to install.
