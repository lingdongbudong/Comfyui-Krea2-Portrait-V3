# Comfyui-Krea2-Portrait-V3

> **Krea2 工作流专用的「摄影人物提示词」随机生成器**（ComfyUI 自定义节点）。
> 纯本地 · 不用大模型 · 不用联网 · 模板填空式：把 **63 个随机池 / 949 条中文条目**
> 按固定 **10 段模板**装配成一段完整提示词，自带角色联动、内容分级、三类权重、可复现种子。

## 这是什么

出人像图最难的是「下一张想换个样子」。这个插件负责那一步：**把提示词写出来**。

- **一键出一条完整中文提示词**，每次 Queue 自动换新（内部带种子，可精确复现）；
- **出完就能拿走** —— 面板里直接选中 / 编辑，点「📋 复制提示词」，**不需要接任何其它节点**；
- **想要的东西可控**：绑定角色、锁定若干字段、给某类选项加权、调内容强度、关掉不想要的补充项；
- **不想要的东西也可控**：去重记忆避免连续抽到同一场景，28 个补充项逐项开关；
- **角色要像本人**：指定角色后，发色 / 发长 / 卷度 / 发态 / 扎法 / 刘海 / 瞳色
  每次重随都保持一致。

> 从 v3.19 起插件**不再生成负面提示词** —— 阴性词表会与「只写画面里有的」这条正文口径互相污染。

## 核心特性

| 特性 | 说明 |
|---|---|
| **纯本地、零依赖** | 只用 Python 标准库 + ComfyUI 本体；不需要任何模型、GPU、网络 |
| **10 段装配** | 镜头 → 人物 → 发型 → 服装 → 姿态 → 表情 → 场景 → 环境光 → 构图 → 附加 |
| **角色联动** | 内置 **2165 位**角色（含作品名 / 标签），按角色特征组织服装、场景、气质、体型 |
| **角色外观锁定** | 默认开：同一角色的发色 / 发型 / 瞳色跨运行、跨重启保持一致（`crc32` 派生，不是 `hash()`） |
| **内容强度五档** | 全年龄 / 暗示 / 露骨 / 强露骨 / 极端，**唯一**的等级控制项 |
| **三类权重** | 轴级权重（选项级）、NSFW 内容项权重（13 项）、外观细节权重（鞋履 6 类 + 水面波光） |
| **双人模式** | 可分别指定角色 A / B，互动段**前置**并**点名**（不出现「她…她」的指代歧义） |
| **字段微调** | 53 个字段可点选候选值 / 手输任意值 / 一键锁定整套 / 重摇 / 清空 |
| **历史与收藏** | 每条可复制全文、放大查看（可就地编辑）、一键复用参数；支持按角色 / 正文 / 种子搜索 |
| **自检报告** | 每次出题都给出等级 / 联动 / 权重 / 冲突纠错 / 字数的可读报告 |

## 三个节点

| 显示名 | 内部 ID | 作用 |
|---|---|---|
| **★ Krea2-Portrait-V3 · 随机出题** | `K2V3GeneratorV2` | 主节点。5 必填 / **40 可选** 控件 / **6 输出端口** |
| **★ Krea2-Portrait-V3 · 提示词预览与编辑** | `K2V3PromptEdit` | 接在出题节点之后，可手动改写（默认**直通不改**，逐字一致） |
| **★ Krea2-Portrait-V3 · 提示词导出** | `K2V3PromptExport` | **不出图也能用**：把提示词 / 报告 / 元数据落成 txt・md・json |

**三种用法**（可只用其中一条）：

```
① 只出题，不出图    K2V3GeneratorV2 ──▶ K2V3PromptExport
② 出题 + 手改        K2V3GeneratorV2 ──▶ K2V3PromptEdit ──▶ K2V3PromptExport
③ 出图               K2V3GeneratorV2 ──▶ CLIPTextEncode ──▶ … ──▶ SaveImage（原生）
```

链路 ① / ② 的终点是「提示词导出」节点，它 `OUTPUT_NODE = True`，
所以 ComfyUI 只执行这条链，**不会去碰 CLIPTextEncode / KSampler / VAE Decode / SaveImage** ——
没装模型、显卡在忙、甚至断网，照样能跑出提示词。

> ⚠️ 节点内部 ID 仍是 `K2V3GeneratorV2` 等，这是**刻意的**：
> ComfyUI 工作流按节点 ID 存，改 ID 会让所有既有工作流打不开。

## 安装

**环境要求**：ComfyUI（0.3.x 及以上）、Python 3.10+。**无需**额外 pip 依赖。

```bash
cd <你的ComfyUI>/custom_nodes
git clone <本仓库地址> Comfyui-Krea2-Portrait-V3
```

没有 git 就下载 ZIP 解压到 `custom_nodes/`，**保证解压出来的目录名是
`Comfyui-Krea2-Portrait-V3`**（这是 ComfyUI 的自定义节点识别方式）。

然后**重启 ComfyUI**（不是只刷新网页）。在节点搜索框输入 `K2 V3`，
能看到上面 3 个节点即安装成功。

> 首次使用建议**刷新一次浏览器页面**，否则插件面板可能还是缓存里的旧内容。

详细的安装、验证与卸载步骤见 **[docs/USAGE.md](docs/USAGE.md#一安装与配置)**。

## 快速上手

**① 只要提示词（推荐先跑这条，不需要装任何模型）**

1. 打开 `workflows/Krea2-Portrait-V3_独立提示词输出.json`（ComfyUI 菜单 → 工作流 → 打开）；
2. 点 **Queue**；
3. 面板下方文本框出现提示词 → 点「📋 复制提示词」；
4. 想换一条：再点一次 Queue（「每次运行重随机」默认开着）；
   想复现某一条：关掉「每次运行重随机」，再把「随机种子」填成上次的值。

**② 要出图**

1. 把「随机出题」拖进画布 → 在**自定义面板**（不是原生控件）里设置；
2. 把输出的「提示词」接到 CLIP Text Encode 的 `positive`；
3. 满意的一套配置点「🗂 方案」存下来，下次一键切回。

**③ 只想试角色 / 试分级**

- 角色：「👤 角色」图鉴里搜名字点选；双人模式下顶部可切换「选给角色 A / 角色 B」；
- 分级：设置面板「① 内容强度」五档直接选，出题范围随之变化。

## 参数速查

出题节点的 **5 个必填**控件：

| 控件 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `内容等级` | COMBO | `sfw` | **已退休**，仅当「内容强度」为旧值「手动（分别设置）」时作兼容兜底 |
| `角色` | COMBO | 自动 | 绑定角色，按其特征组织提示词 |
| `角色联动` | BOOLEAN | ✅ | 关闭则完全随机（仅保留角色名） |
| `每次运行重随机` | BOOLEAN | ✅ | 每次 Queue 出一条新的 |
| `随机种子` | INT | 0 | 关掉重随机后改它即可精确复现 |

**40 个可选**控件中常用的几个：

| 控件 | 默认 | 范围 |
|---|---|---|
| `内容强度` | 全年龄 | 全年龄 / 暗示 / 露骨 / 强露骨 / 极端 |
| `人物数量` | 单人 | 单人 / 双人 |
| `第二角色` | 自动 | 2165 位角色（双人时可分别点名 A / B） |
| `联动强度` | 1.0 | 0.0 – 1.0 |
| `去重记忆` | 0 | 0 – 20（0 = 关） |
| `多样性温度` | 1.0 | 0.5 – 2.0 |
| `批次数` | 1 | 1 – 8（第 1 条是主输出，其余进「候选列表」端口） |
| `角色外观锁定` | ✅ | 同一角色外观跨运行一致 |
| `关闭可选项` | 空 | 逗号分隔的补充项 id，28 项可关 |
| 13 个 `…权重` | 1.00 | 0.0 – 5.0（NSFW 内容项） |
| 6 个鞋履 `…权重` + `水面反光权重` | 1.00 | 0.0 – 3.0 |

> 全部 40 个可选控件、每个面板功能区、以及权重的计算口径，
> 都在 **[docs/USAGE.md](docs/USAGE.md#三主要功能与参数说明)** 里逐项写清楚了。

## 常见问题

**Q：装完在节点列表里搜不到？**
先确认目录名是 `Comfyui-Krea2-Portrait-V3`、并且**重启过 ComfyUI**（不是刷新网页）；
再看启动日志里有没有这个插件的报错。刷新浏览器可解决「面板还是旧样子」。

**Q：为什么提示词里有些内容没出现？**
模板填空式生成，很多字段是**概率出现**的。固定的只有镜头 / 人物 / 发型 / 服装主件 / 姿态 /
场景 / 构图等核心项；道具、天气、发饰、袜鞋、纹身、瑕疵等 28 个补充项会被随机跳过。

**Q：角色图鉴里很多角色没有头像？**
仓库**不含**缩略图（约 40 MB）。没有图时会退回首字色块，**不影响出题** ——
出题只用角色名，不用图片。

**Q：出的图和别人的不一样 / 想复现上一条？**
关掉「每次运行重随机」，把「随机种子」填成上一条的值；或在「历史」里点「↩ 复用此参数」——
它会顺手关掉重随机（复用本来就是「要复现那一条」）。

**Q：同一个角色每次发型都变？**
确认「角色外观锁定」是开着的（默认开），且「角色」不是「自动」。
该开关只锁外观七项，不影响服装与场景。

**Q：能用在别的模型上吗？**
正文是**中文自然语言**，按 Krea2 的口径写的。别的中文理解模型通常也能用，
但效果未做验证。

**Q：会联网吗？会上传我的提示词吗？**
不会。运行时（出题 / 出图 / 看图鉴）**全程不发任何外部请求**，
生成过程完全在本机完成。

**Q：我把提示词发到网上可以吗？**
请自行判断。注意角色名与作品名的知识产权归各自权利人，且生成内容由使用者自行负责。

更多问题见 **[docs/USAGE.md](docs/USAGE.md#五常见问题faq)**（含 20+ 条）。

## 兼容性与已知限制

| 项 | 说明 |
|---|---|
| ComfyUI 版本 | 在 **0.37.4** 上验证；理论上 0.3.x+ 均可 |
| Python | 3.10+（验证于 **3.12.10**） |
| 额外依赖 | **无**（不用 numpy / PIL / torch 也能跑出词） |
| 输出语言 | **只有中文**。库内能译的已译成中文，译不出的英文条目已删除；唯一豁免是**角色英文原名** |
| 字数上限 | 单人 ≤ **600 字**，双人 ≤ **1000 字**（超限会按顺序精简，报告里会说明） |
| 控件兼容 | 新增控件**一律追加在末尾**；退休控件**只撤界面、保留控件位**，因此旧工作流不会错位 |
| 不发负面提示词 | v3.19 起取消，出题节点没有负面词端口 |

## 署名与来源

- **插件作者**：灵冻不冻

本插件的词库与生成逻辑均由该 HTML 脚本移植而来：

| HTML 脚本里的东西 | 在本仓库里 |

| 全部词库（63 池 / 949 条） | `presets/k2_v3_pools.json`（由 `tools/export_k2v3_pools.mjs` 从 HTML 导出，零漂移） |
| `buildPrompt()` 的 10 段装配 | `krea2_v3_rules.build_prompt()` |
| 两级级联随机 + 冲突预过滤 + 兜底纠错 | `randomize_*()` / `_prefilter()` / `enforce_conflicts()` |
| `runSelfCheck()` 的 F1–F10 / S1–S13 | `run_self_check()` |
| 超字数按顺序精简 | `generate()` 里的 `TRIM_ORDER` |

> ⚠️ **词库的唯一真源仍是那份 HTML**：改词库要**同时**改 HTML 与 JSON，
> 只改 JSON 会在下次导出时被冲回。

角色名称与作品名称的知识产权归各自权利人所有，本项目仅作提示词检索与描述之用。
